# 角色创建引导器

一个无需安装、无需服务器的半自动车卡与人物档案工具。玩家可以像完成电子游戏的新手引导一样完成车卡，随后在人物卡管理页持续记录生命、资源、状态、背包与成长。

## 直接使用

双击 `index.html` 即可开始车卡；打开 `manager.html` 可进入人物卡管理。车卡进度和人物档案自动保存在当前浏览器中，并可导出完整备份。

建议通过本地网页服务或 GitHub Pages 打开，以获得最稳定的浏览器体验；软件本身不依赖后端、数据库或账号。

## 部署到 GitHub Pages

1. 新建一个 GitHub 仓库。
2. 将本文件夹中的全部文件上传到仓库根目录。
3. 打开仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**。
5. 选择 `main` 分支和根目录 `/`，保存。

稍等片刻后，GitHub 会给出可公开访问的网址。所有角色资料只保存在玩家自己的浏览器中，不会上传到网站。

## 已实现的规则辅助

- 27 点购点与背景属性上限检查
- 18 项正式背景与自创背景预算向导
- 初始学派训练、技能重复规避与背景豁免自动选择
- 1–30 OP 预算与学派节点前置检查
- 多学派 OP 分配、初始学派／主学派区分与兼修顺序记录
- 6 组重度冲突、8 组轻度冲突与主学派一半上限自动检查
- 熟练加值、生命值、AC、先攻、技能、学派攻击与豁免 DC 自动计算
- 熟练武器筛选、武器伤害与标签速览
- OP 4／8／12／16 的专长或属性提升记录
- 角色形象／Token 上传、方形裁切压缩，并随存档和独立角色卡导出
- 设备本地自动保存、JSON 存档、独立 HTML 角色卡、直接下载分页 PDF 与浏览器打印
- 多角色档案、当前／临时生命、死亡豁免、力竭与状态管理
- 可自定义资源计数、短休／长休恢复方式、背包数量、负重、装备与货币管理
- 从人物卡直接提高总 OP 并回到原车卡继续升级，升级后保留游玩资源和背包
- 单角色导出、全部档案备份与跨设备读取

## 文件说明

- `index.html`：网页入口
- `styles.css`：界面与打印样式
- `data.js`：背景、学派、节点、武器与专长数据
- `app.js`：引导流程、校验、计算、保存与导出逻辑
- `manager.html`、`manager.css`、`manager.js`：人物卡管理界面
- `character-store.js`：多角色档案、游玩数据与升级衔接
- `html2canvas.min.js`、`jspdf.umd.min.js`：本地 PDF 生成依赖

这是纯静态网页；修改文件后直接刷新即可，不需要构建步骤。
